01

PROJECT OVERVIEW

The goal of this project is to design and build a laboratory test bench capable of evaluating electric vehicle compressors across a wide range of operating conditions. The system reproduces vehicle thermal loads while allowing key operating conditions to be independently controlled and measured.

I initially worked on the system as part of a senior capstone team and later continued development as the project lead, focusing on system design, component selection, analysis, controls, instrumentation, and preparation for testing.

02

SYSTEM DESIGN

The test bench combines an R290 refrigerant loop with a temperature-controlled coolant system. The refrigerant loop contains the compressor, condenser, expansion valve, and evaporator.

Hot and cold coolant reservoirs and controllable pumps allow the operating conditions supplied to the condenser and evaporator to be independently adjusted.

03

ENGINEERING & CONTROLS

MATLAB, CoolProp, and GT-SUITE were used to evaluate refrigerant behavior, heat exchanger performance, pressure drop, thermal loads, mass flow rates, and compressor operating conditions. This analysis supported component selection and system design.

The physical system integrates the refrigeration loop, coolant conditioning hardware, instrumentation, controls, and data acquisition into a single test platform.

04

SYSTEM INTEGRATION

Mechanical layout and component integration were developed around system packaging, fluid routing, instrumentation, accessibility, and preparation for experimental testing.
